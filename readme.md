# Файловый менеджер file_manager.py

## Функционал приложения
+ копирование файлов,
+ удаление файлов и папок,
+ подсчет количества файлов в текущей папке и во всех вложенных папках,
+ добавление текущей даты к имени одного файла или к именам всех файлов указанной папки,
+ поиск папки внутри указанной папки.

## Запуск приложения
Для запуска приложения необходимо в командной строке набрать команду

**python file_manager.py \<command> [options]**

## Команды
+ **copy \<source> \<destination>** - копировать файл
+ **delete \<path>** - удалить файл или папку
+ **count \<path>** - подсчитать кол-во файлов в папке
+ **add_date \<path>**  - добавить дату создания к имени файла или файлов внутри папки
+ **search \<source_dir> \<destination_dir>** - поиск папки внутри каталога с выводом пути к нему
